# 🌤️ Python Weather App

A simple command-line weather application built with python that fetches real-time weather data using OpenWeatherMap API.

## ✨ Features
- Get current temperature, weather description, humidity, and wind speed
- Search by city name

## 🛠️ How to run
1. Install requests: ‘pip3 install requests’
2. Add your OpenWeatherApp API key to the script
3. Run: ‘python3 weather.py’
